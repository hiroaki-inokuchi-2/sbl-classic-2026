■■■ 1. Gemini CLI のインストール (初回のみ) ■■■

このプロジェクトの一部の手順は `gemini-cli` を利用するとスムーズに行えます。
以下の手順でインストールしてください。


1-1. Node.js のインストール:
   --------------------------
   まだインストールしていない場合は、Node.js公式サイトからLTS版をインストールしてください。
   https://nodejs.org/


1-2. Gemini CLI のインストール:
   --------------------------
   ターミナルで以下のコマンドを実行し、`gemini-cli` をインストールします。

   ```
   npm install -g @google/gemini-cli
   ```


1-3. 初期セットアップ:
   --------------------------
   インストール後、初めて `gemini` コマンドを実行すると、Googleアカウントでの認証などの
   初期設定が案内されます。画面の指示に従ってセットアップを完了してください。

   ```
   gemini
   ```


============================================================
 2. 開発環境のセットアップ
============================================================


■■■ A. Gemini CLI を利用する場合 ■■■

`gemini-cli` をインストール済の場合、リポジトリをクローンした後、
以下の指示をコピーして `gemini-cli` に貼り付けるだけで環境構築が完了します。

   +-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+
   （↓ここからコピー）

   このプロジェクトのセットアップを行います。
   まず、`npm install` を実行して、開発に必要なライブラリをすべてインストールしてください。
   次に、`npm run dev` を実行して、開発サーバーを起動してください。

   （↑ここまでコピー）
   +-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+


■■■ B. 手動でセットアップする場合 ■■■

2-1. 前提条件:
   --------------------------
   - Node.js (バージョン18以上推奨) と npm がPCにインストールされていること。
   - Git がインストールされていること。


2-2. プロジェクトのセットアップ:
   --------------------------
   a. ターミナルを開き、次のコマンドでプロジェクトを自分のPCにコピーします。
      ```
      git clone https://github.com/hiroaki-inokuchi-2/sbl-classic-2026.git
      ```

   b. コピーしたプロジェクトのフォルダに移動します。
      ```
      cd sbl-classic-2026
      ```

   c. 次のコマンドを実行して、開発に必要なライブラリをすべてインストールします。
      ```
      npm install
      ```


2-3. 開発の始め方:
   --------------------------
   a. 次のコマンドを実行すると、開発用のサーバーが起動します。
      ```
      npm run dev
      ```

   b. ターミナルに表示された `http://localhost:xxxx` のようなURLをブラウザで開くと、
      開発中のWebアプリが表示されます。

   c. `src` フォルダ内のファイルを編集すると、自動的にブラウザの表示も更新されます。

============================================================
 4. 新しいアプリを作成する場合
============================================================

`gemini-cli` に「新しいアプリを作成してほしい」と伝えてください。
その際、以下の情報を伝えるとスムーズです。

- アプリの名前（例: 「ブログサイト」）
- どのような機能を持たせたいか（例: 「記事の一覧表示、詳細表示、コメント機能」）
- （任意）GitHubのリポジトリURL（新しいリポジトリを空の状態で作成しておくと、私がGitの初期設定まで行います）

新しいアプリは、`src/` フォルダ内に専用のサブフォルダとして作成されます。


============================================================
 5. コード品質のためのコマンド
============================================================

- コードを整形して統一感を保つために、いつでも次のコマンドを実行できます。
  ```
  npm run format
  ```

- コードに潜在的な問題がないかチェックするには、次のコマンドを実行します。
  ```
  npm run lint
  ```
